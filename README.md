One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: a fridge that dims its light politely at midnight, whispers "we both know you're not hungry, you're bored," and locks the cheese drawer until morning.

## Run it

```sh
python3 main.py
```

Writes the pitch (150 characters, one sentence) to `/output/entry.txt`.
